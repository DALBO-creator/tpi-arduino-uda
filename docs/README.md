## Quick Start

```bash
# 1. Clona il repository
git clone https://github.com/tuouser/tpi-arduino-uda.git

# 2. Carica lo sketch su Arduino
# (Apri arduino/monitoraggio/monitoraggio.ino con Arduino IDE)

# 3. Avvia l'applicazione Python
cd python
uv sync
uv run app.py
```
